# QuickNotes App

QuickNotes is a clean and lightweight note-taking web application designed to help users quickly capture, categorize, search, and manage daily thoughts and tasks.

## Features
- Add notes with categories (Personal, Work, Study).
- Real-time character validation and error reporting.
- Instant search filter to find specific notes.
- Persistent data storage using browser `localStorage`.
- Responsive layout with mobile-friendly stacking controls.

## How to Run Locally
1. Clone or download this repository to your computer.
2. Open the `quicknotes-app` folder.
3. Open `index.html` directly in any modern web browser.

## What I Learned
1. How to dynamically build elements safely using `createElement` and `textContent` to avoid XSS vulnerabilities.
2. Implementing data persistence across browser reloads using JSON parsing and `localStorage`.
3. Writing flexible CSS layouts with Flexbox and responsive media queries.
